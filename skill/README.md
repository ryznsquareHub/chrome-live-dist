# 스킬 문서

- 원본: 이 폴더의 `SKILL.md` (git으로 관리).
- Claude Code가 읽는 사본: `%USERPROFILE%\.claude\skills\chrome-live\SKILL.md` — 스킬은 그 폴더에 실제 파일이 있어야 로드되므로 포인터가 아니라 **전체 사본**을 둔다.
- 고친 뒤 동기화: `C:\path\to\chrome-live\skill\sync-skill.cmd` (사본의 `C:\path\to\chrome-live`를 이 저장소의 실제 폴더로 바꿔 씀 → 다른 PC·다른 폴더에 설치해도 맞음. 주인 PC에서는 원본과 같은 내용)
- 확인: `fc C:\path\to\chrome-live\skill\SKILL.md %USERPROFILE%\.claude\skills\chrome-live\SKILL.md`
